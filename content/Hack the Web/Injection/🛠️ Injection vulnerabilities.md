## Injection vulnerabilities

>[!warning] Stub sub-root. Injection branch of [[Web application security testing methodology]]. WSTG category `WSTG-INPV`.

- Injection occurs when untrusted input crosses into an interpreter — SQL, a shell, a template engine, an XML/LDAP query, or a deserializer — and is parsed as code rather than data.
